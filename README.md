# 赵松涛 | Personal Portfolio

一个围绕工业软件、计算几何与 CAD 内核设计的中英文个人简历网站。

A bilingual portfolio focused on industrial software, computational geometry, and CAD kernels.

## Features

- 中文 / English 即时切换
- 响应式桌面与移动端布局
- 深色 / 浅色主题
- 交互式 CAD 曲面线框
- 滚动进度与渐入动效
- 无框架、无构建步骤

## Run locally

```bash
python -m http.server 4173
```

访问 `http://127.0.0.1:4173/`。
